Recent Updates

Patch-style progress summary

A snapshot of the fixes and improvements that moved the build forward.

Combat flow and battle control

  • Reviving is now possible
  • Restarting battles is now possible
  • Rest points before the boss were added
  • Boss turn order was fixed so extra turns no longer occur

Status effects and rules

  • Percent-chance moves were added, including Hush at 20 percent
  • Status effects apply immediately with the exception of stun timing
  • Silence now blocks special skills without blocking healing
  • Burn and bleed messaging was corrected

UI, feedback, and polish

  • Silence, HP, MP, and shield requirements now explain why a move cannot be used
  • Reap can no longer be canceled during the healing phase
  • Highlighted-character issues were fixed when canceling healing
  • Animation skidding was corrected for Cale and Mr. Depel

Dialogue and dynamic events

  • Battle dialogue and branching side dialogue were added
  • Dialogue triggers now react to player usage and move usage
  • Mid-battle events can add players based on health thresholds
  • Repeated status application no longer causes mumbled or jumbled words

Bug fixes

  • Damage is no longer applied twice during affected sequences
  • Reap healing no longer inherits the same duplicate-damage bug path
  • Boss turn logic was stabilized for consistent pacing
  • Multiple item-use dialogue issues were cleaned up

System notes

  • Most iteration is driven by rules clarity, UI messaging, and player feedback
  • Testing focuses heavily on edge cases like status stacking and turn flow
  • Polish work follows behavior fixes so the presentation reflects the new rules

Next Fixes

Known issues being tracked

Keeping the rough edges visible is part of keeping the project honest and improving it well.

  • When silenced, Reap skips the damage phase and still plays the healing phase, which can create edge cases including healing at 0 HP.
  • If damage is recorded before silence is applied, the update does not always refresh correctly and Nekro can still heal even when the damage phase is skipped.
  • Stun should end when a player or enemy is attacked, so that rule still needs to be adjusted.
